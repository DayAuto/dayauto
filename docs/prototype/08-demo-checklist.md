# 08. 시연 체크리스트

> P6에서 보완한다. 아래는 지금까지 확정된 필수 항목이다 (06 문서 N-08, N-15).

## 시연 1~2일 전

- [ ] 시연 계정으로 앱에서 **재로그인**한다. 구글 OAuth 테스트 모드의 refresh token은 7일 뒤 만료된다. (재로그인 시 DB 토큰은 `events.signIn`에서 갱신된다 — N-07)
- [ ] 시연 계정이 구글 Cloud 콘솔 OAuth 동의 화면의 **테스트 사용자**에 등록되어 있는지 확인한다.

## 시연 전날

- [ ] **Supabase 무료 프로젝트가 활성 상태인지 확인**한다. 7일간 미사용이면 일시정지된다. 일시정지되어 있으면 대시보드에서 복구하고 `npm run dev`로 로그인까지 확인한다.

## 시연 당일

- [ ] `.env.local`의 **`DEMO_NOW`를 제거(또는 주석 처리)** 하고 dev 서버를 재시작한다.
- [ ] **회식 일정 없이** 앱을 먼저 한 번 열어 동기화·주간 배분을 끝낸다. (회식을 먼저 넣으면 첫 진입 자동 동기화가 회식을 배분에 반영해 조정안이 뜨지 않는다.)
- [ ] 그 다음 구글 캘린더에 "팀 회식 19:00–23:00"(오늘)을 추가하고 [동기화]를 누른다.
