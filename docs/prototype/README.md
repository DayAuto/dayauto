## 원칙 (모든 문서에 우선)

1. **범위는 01 문서가 기준**이다. 엑셀 요구사항 정의서의 나머지 기능은 구현하지 않는다.
2. **일정 계산은 결정론적 엔진(`src/server/engine`)만** 한다. 런타임 LLM 호출 0회.
3. 문서에 없는 결정이 필요하면, 가장 단순한 쪽으로 구현하고 **06 문서의 "구현 중 추가 결정" 표에 한 줄 기록**한다. 조용히 정하지 않는다.
4. 원문서(프로젝트 개요서·요구사항 정의서·기능 명세서·ERD 초안)와 이 문서가 다르면 **이 문서를 따르고**, 차이는 06 문서에 이미 기록되어 있다.
