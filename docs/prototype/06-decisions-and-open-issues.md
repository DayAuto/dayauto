# 06. 결정 기록과 미결 사항 (팀 검토용)

초기 웹을 AI에게 일임하면서 **원문서에 없거나 서로 어긋나는 부분을 AI가 임의로 정했다.** 디버깅 단계에서 이 표부터 검토해 뒤집을 것은 뒤집는다. 뒤집을 때는 "상태"를 `변경`으로 바꾸고 결정 내용을 적는다.

## 3. 알려진 한계 (시연 시 질문 대비)

- 실시간 감지가 아니다. [동기화]를 눌러야 감지된다 (프로토타입 결정 1).
- 화면에 LLM이 돌아가는 모습은 없다. 커리큘럼 데이터를 LLM으로 만들었다는 설명이 필요하다 (프로토타입 결정 2).
- 이번 주만 다룬다. 다음 주로 넘긴 분량은 다음 주 월요일 배분에서 반영된다.
- 완료 체크가 없어 잔여량은 "배정된 양" 기준으로 줄어든다 (실제로 공부했는지와 무관).
